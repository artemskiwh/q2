# Pakhlava — сайт ресторана кавказской кухни

Статический сайт на Next.js 14 (App Router, `output: export`), деплой на GitHub Pages
через `.github/workflows/deploy.yml`.

Стилистика собрана по фирменному медальону: тёмный сланец, тонкая антиква Cormorant,
золотые волосяные линии и кавказский орнамент.

## Страницы

| Путь        | Что внутри                                                                 |
| ----------- | -------------------------------------------------------------------------- |
| `/`         | Первый экран-медальон, быстрая бронь, философия, хиты меню, залы, отзывы    |
| `/menu`     | Полное меню: поиск, фильтры по тегам, разделы с якорями                     |
| `/booking`  | Онлайн-запись в три шага + «Мои брони»                                      |
| `/about`    | История, день на кухне, принципы, залы, галерея                             |
| `/contacts` | Адрес, часы, связь, как добраться                                           |

## Команды

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # статическая сборка в ./out
```

## Где что менять

- `lib/restaurant.ts` — адрес, телефон, почта, часы работы, соцсети, залы, поводы,
  принципы, отзывы, настройки брони (часы приёма, шаг слотов, максимум гостей онлайн).
- `lib/menu.ts` — категории и блюда. Поле `signatureIds` задаёт витрину на главной.
- `lib/booking.ts` — слоты, формат телефона, коды броней, хранилище.
- `tailwind.config.ts` + `app/globals.css` — цвета, типографика, кнопки, поля.

## Как добавить фотографии

Фотографий пока нет — вместо них выводится орнаментальная «тарелка». Чтобы
подставить снимок, достаточно положить файл в `public/img/` и указать путь:

```ts
// lib/menu.ts
{
  id: "khinkali-beef",
  name: "Хинкали с говядиной и свининой",
  image: "/img/menu/khinkali.jpg",   // ← добавить эту строку
  …
}
```

То же работает для залов (`halls[].image` в `lib/restaurant.ts`) и для плиток
галереи (`TILES[].image` в `components/Gallery.tsx`).

Рекомендации: горизонтальные кадры 4:3 для карточек блюд, 16:10 для залов,
тёмный фон, тёплый боковой свет. Ширина 1200–1600 px, `.jpg` или `.webp`.

## Онлайн-бронирование

Сайт статический, backend'а нет: бронь формируется на клиенте, сохраняется
в `localStorage` (ключ `pakhlava:bookings`) и показывается гостю с кодом вида
`PKH-XXXX` и файлом `.ics` для календаря.

Чтобы заявки уходили в ресторан, в `components/BookingForm.tsx` в функции `submit`
рядом с `saveBooking(booking)` нужно добавить отправку на реальный приёмник —
например, в Telegram-бота, на почту или в CRM:

```ts
await fetch("https://<ваш-эндпоинт>", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(booking),
});
```

## Черновые данные

Адрес, телефон, ссылки на соцсети и отзывы — заглушки. Перед публикацией их нужно
заменить на настоящие в `lib/restaurant.ts`.
