# Pakhlava — сайт ресторана кавказской кухни

Статический сайт на Next.js 14 (App Router, `output: export`).

Живая версия: **https://artemskiwh.github.io/q2/**

Деплой автоматический: `.github/workflows/deploy.yml` на каждый push в `claude/**`
собирает `./out` и публикует его в ветку `gh-pages` — именно из неё GitHub Pages
отдаёт сайт. Базовый путь `/q2` задан в `next.config.mjs`.

Оформление чёрно-белое: глубокий чёрный фон, белая типографика и тонкие линии.
Шрифты — Montserrat (заголовки), Manrope (текст) и Cormorant (логотип-вывеска).

## Страницы

| Путь        | Что внутри                                                                 |
| ----------- | -------------------------------------------------------------------------- |
| `/`         | Первый экран, быстрая бронь, бегущая строка, хиты меню, отзывы, контакты    |
| `/menu`     | Полное меню: поиск и разделы с якорями                                      |
| `/booking`  | Онлайн-запись одной формой: дата, время, гости, контакты, пожелания         |
| `/about`    | История, день на кухне, принципы, залы, галерея                             |
| `/contacts` | Адрес, часы, связь, как добраться                                           |

## Команды

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # статическая сборка в ./out
```

## Где что менять

- `lib/restaurant.ts` — адрес, телефон, почта, часы работы, соцсети, залы, поводы,
  принципы, отзывы, настройки брони (часы приёма, шаг слотов, максимум гостей онлайн).
- `lib/menu.ts` — категории и блюда. Поле `signatureIds` задаёт витрину на главной.
- `lib/booking.ts` — слоты, формат телефона, коды броней, хранилище.
- `tailwind.config.ts` + `app/globals.css` — цвета, типографика, кнопки, поля.

## Как добавить фотографии

Заглушек на месте фотографий нет: блок с картинкой появляется только тогда,
когда фотография указана. Достаточно положить файл в `public/img/` и прописать путь.

**Блюда** — `lib/menu.ts`:

```ts
{
  id: "khinkali-beef",
  name: "Хинкали с говядиной и свининой",
  image: "/img/menu/khinkali-beef.jpg",   // ← добавить эту строку
  …
}
```

Одна и та же карточка используется и в меню, и на главной: на телефоне это
строка с квадратным снимком слева, на широком экране — карточка с кадром 4:3
сверху. Пока фотографии нет, на её месте ровная тёмная плашка того же размера —
сетка не прыгнет, когда снимки появятся.

**Залы** — поле `image` в массиве `halls` (`lib/restaurant.ts`), кадр 16:10.

**Галерея** — поле `image` у плиток в `components/Gallery.tsx`. Пока ни у одной
плитки нет фото, раздел «Атмосфера» на странице «О ресторане» не показывается.

**Первый экран** — `heroImage` в `lib/restaurant.ts`, например `/img/hero.jpg`.
Фон затемняется автоматически, чтобы кнопки читались.

Рекомендации по кадрам: горизонтальные, ширина 1600–2000 px для фона первого
экрана и 1200–1600 px для блюд, формат `.jpg` или `.webp`, вес до 400 КБ.
Имя файла — латиницей, лучше по id блюда.

## Онлайн-бронирование

Сайт статический, backend'а нет: бронь формируется на клиенте и показывается
гостю с кодом вида `PKH-XXXX` и файлом `.ics` для календаря. Никуда не отправляется
и нигде не хранится.

Чтобы заявки уходили в ресторан, в `components/BookingForm.tsx` в функции `submit`
рядом с `saveBooking(booking)` нужно добавить отправку на реальный приёмник —
например, в Telegram-бота, на почту или в CRM:

```ts
await fetch("https://<ваш-эндпоинт>", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(booking),
});
```

## Что ещё черновое

Адрес, телефон, почта, Instagram и ссылка на отзывы 2ГИС — настоящие. Остаётся
заменить в `lib/restaurant.ts`:

- `halls` — названия, вместимость и описания залов пока придуманы;
- `values` — тексты о кухне на странице «О ресторане»;
- страница `/about` осталась в проекте, но убрана из навигации и подвала.

Контакты, режим работы (10:00 — 23:00 ежедневно) и отзывы — настоящие: отзывы
взяты с 2ГИС, только с оценкой «5».

Меню в `lib/menu.ts` тоже черновое: состав разделов и цены нужно сверить с реальными.
